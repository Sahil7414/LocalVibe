1. Executive Summary & Problem Definition

LocalVibe is a full-stack, hyper-local community discovery platform specifically engineered for Indian metropolitan hubs and neighborhoods. In modern urban environments, finding niche, authentic, and spontaneous social gatherings (such as tech meetups, book clubs, sunrise yoga sessions, open-mic poetry, and board game meetups) is heavily fragmented across siloed messaging groups and generic commercial ticketing portals.

Core Mission
Empower urban residents, remote workers, students, and creators to discover, organize, attend, and navigate nearby gatherings with zero friction, instant interactive geospatial mapping, and high-trust community moderation.

Key Solution Pillars

🗺️ Geospatial Discovery
Interactive Leaflet.js map with custom category markers, 500m walkable radar radius, and automatic viewport-bound queries.
📍 Smart City Resolution
Database of 28+ Indian metros with fuzzy neighborhood-to-metro normalization, reverse geocoding, and 1-click GPS sync.
📅 RSVP & Calendar Sync
Optimistic RSVP tracking with concurrency-safe counts and native exports for Google, Apple iCal (.ics), and Outlook.

2. System Architecture & Tech Stack

LocalVibe is built as a decoupled, modern multi-tier Single-Page Application (SPA) backed by a high-performance Express REST API and a resilient dual-layer data store.

Tier / Domain Technology Key Function & Architecture Rationale
Frontend Client React 18, Vite Fast HMR builds, component-driven UI, declarative lifecycle management, and optimistic state updates.
Mapping Engine Leaflet.js, React-Leaflet Zero-cost OpenStreetMap integration, performant vector circles (500m Walkable Radar), and custom HTML pins.
State & Auth Context API Global state management for Auth (JWT persistence), Location (GPS/City switch), and Toast notifications.
Backend API Node.js, Express.js Modular Controller-Service-Repository pattern, rate-limited middleware, and centralized error handling.
Primary DB MongoDB Atlas Mongoose ODM, 2dsphere geospatial indexing for GeoJSON coordinates, compound indices for RSVP constraints.
Fallback DB In-Memory Store Zero-dependency dev & offline fallback pre-seeded with 30 realistic Indian events and 8 authenticated test users.
Security Bcrypt.js, JWT, CORS Secure password hashing (10 salt rounds), HMAC SHA-256 tokens, input sanitization via express-validator.

3. Core Feature Breakdown & Engineering Details

3.1 Interactive Geospatial Map Discovery

  • Leaflet Map Canvas: Dynamic map rendering with smooth zoom/pan animations, custom pin popups, and auto-centering based on user location.
  • 500m Walkable Radar: Visual geofence overlay highlighting events within short walking distance of the selected center point.
  • Dual-Mode Layout: Seamless switching between split Map + Grid mode and Full-Width Grid mode on desktop and mobile devices.

3.2 Intelligent Indian City Hub & Normalization

The geocoding subsystem (geocodingService.js) features an Indian metropolitan hub supporting 28+ cities:

Covered Major Metros
Mumbai, Delhi NCR, Bengaluru, Pune, Hyderabad, Chennai, Kolkata, Ahmedabad, Jaipur, Goa, Kochi, Chandigarh.
Covered Emerging Hubs
Lucknow, Indore, Surat, Bhopal, Vadodara, Coimbatore, Visakhapatnam, Varanasi, Amritsar, Dehradun, Guwahati, Mysore.
  • Fuzzy Alias Mapping: Automatically maps micro-neighborhoods (e.g., Bandra, Juhu, Thane → Mumbai; Hauz Khas, Gurugram, Noida → Delhi NCR; Koramangala, Indiranagar → Bengaluru).
  • Proximity Matching: Calculates Haversine spherical distance (< 80 km) to assign raw GPS coordinates to the nearest regional hub.
  • Nominatim Integration: Live OpenStreetMap address search prioritized with &countrycodes=in.

3.3 Event Lifecycle & Creator Publishing Flow

  • Publishing Wizard: Form supporting title, rich multiline description, category selection, price (Free or ₹ INR), start/end date-times, and venue address.
  • Interactive Pin Drop: Creators can click anywhere on the Leaflet map to set exact GPS venue coordinates, with instant reverse-geocoding.
  • Quick Neighborhood Presets: City-specific 1-click venue chips (e.g. BKC, Kala Ghoda, CyberHub, Koramangala).
  • Image Handling: Supports both high-res curated preset images, direct web URLs, and client-side Base64 image uploads (under 5MB).

3.4 RSVP, Attendance & Calendar Export Engine

  • Mutual Exclusivity: Users can toggle between GOING and INTERESTED; status updates atomically decrement/increment server attendee counts.
  • Apple iCal (.ics) Generator: Generates RFC 5545 compliant VCALENDAR blob files client-side for iOS and macOS Calendar import.
  • Google & Outlook Deep Links: Timezone-normalized TEMPLATE URLs for 1-click cloud calendar integration.

5. REST API Endpoints Specification

Method Route Endpoint Auth Description
POST /api/auth/register Public Register a new user account with bcrypt password hashing
POST /api/auth/login Public Authenticate user credentials and return JWT bearer token
GET /api/auth/me Bearer Fetch authenticated user profile and active RSVPs
GET /api/events Public List events with filtering (city, category, search, timeframe, price)
GET /api/events/:id Public Retrieve full event details, organizer profile, and RSVP counters
POST /api/events Bearer Create and publish a new event with GeoJSON coordinates
POST /api/rsvp/:eventId Bearer Submit or toggle GOING / INTERESTED RSVP status
GET /api/rsvp/my-events Bearer Get user's registered, bookmarked, and hosted events
POST /api/admin/events/:id/suspend Admin Moderate and suspend an event violating community guidelines
